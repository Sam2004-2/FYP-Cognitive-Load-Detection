# Privacy and Data Handling

## Data Collected by the App

The study flow stores:

- participant IDs generated by the system
- study responses and task outcomes
- delayed-test responses
- computed feature windows and CLI samples
- intervention logs
- optional site-activity events used by the admin dashboard

## Data Not Stored by Default

This repository does not indicate that the backend stores:

- raw webcam video
- raw landmark streams as primary report artifacts
- demographic data

## Storage

- report JSON files are stored under `CLE_REPORTS_DIR`
- admin export endpoints read from the stored report files
- admin routes are protected by `CLE_ADMIN_TOKEN`

## Operational Notes

- keep `CLE_ADMIN_TOKEN` private
- keep exported report bundles in a controlled location
- review participant-facing text in `UI/public/study-instructions.md` before submission or deployment
