# Study UI

This directory contains the React/TypeScript frontend for the study flow and admin dashboard.

## Main Routes

- `/`
- `/study/setup`
- `/study/session`
- `/study/summary`
- `/study/delayed`
- `/admin`

## Local Development

```bash
npm install
npm start
```

If needed, create `.env.local` from [./.env.example](./.env.example) to point the UI at a backend.

For the wider project docs, see [../docs/README.md](../docs/README.md).
